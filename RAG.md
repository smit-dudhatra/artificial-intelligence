RAG stands for Retrieval-Augmented Generation. [1]  
It is an artificial intelligence (AI) technique used to improve the accuracy and reliability of large language models (LLMs). It works by fetching relevant facts from an external knowledge base before the model generates an answer. [1, 2, 3]  

How RAG Works 

• Retrieval: When you ask a question, the system searches an external database or documents for matching information. 
• Augmentation: The system adds the retrieved facts to your original question to create a context-rich prompt. 
• Generation: The AI model reads the prompt with the added context and writes an accurate, grounded response. [7, 8]
